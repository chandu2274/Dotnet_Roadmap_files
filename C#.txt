-> What is C#?
C# is a programming language developed by Microsoft. It is used to build web applications, APIs, desktop applications, and cloud applications.

-> What is .NET?
.NET is the platform that provides the tools and runtime needed to build and run C# applications.

-> What is the difference between C# and .NET?
Answer: C# is a programming language developed by Microsoft, while .NET is a development platform used to build and run applications written in C# and other supported languages.

-> What is .NET Runtime?
Answer: The .NET Runtime is the execution environment that runs .NET applications. It manages tasks such as executing code, memory management, and garbage collection.
Example: When you run dotnet run, the .NET Runtime executes your application

-> Variables and Data Types
A variable is a named place in memory used to store a value.

ex: int age = 25;

Here:

int → data type
age → variable name
25 → value

-> Common C# Data Types
int,long,double,decimal,float,char,string,bool

->Type Casting
Type casting means converting one data type into another data type.

Ex: int age = 25;
double number = age;

Console.WriteLine(number);

->how many types of casting

Implicit Casting and Explicit Casting

string ageText = "30";
int age = int.Parse(ageText);
